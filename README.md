# Robinhood Faucecat — $FAUCECAT

Мем-лендинг под концепт: кот в зелёной шляпе Робин Гуда пьёт крипту прямо из
крана, пародия на faucet.testnet.chain.robinhood.com. Идея — "кран, который
грабит богатых и капает бедным": кот-Робин Гуд подключился к резервуару
китов и раздаёт дрип всем желающим.

Чистый статический HTML/CSS/JS, без сборки.

## Структура
- `index.html` — разметка
- `style.css` — стили (зелёный кран + фиолетовый дрип + чёрный фон, шрифты Fredoka/JetBrains Mono)
- `script.js` — вся логика (CONFIG с ссылками/CA, копирование CA, бургер-меню, тикер, drip-лог, счётчики, DexScreener)
- `assets/faucecat-mascot.jpg` — лого/маскот

## Деплой
Просто статические файлы — заливаются на GitHub, импортируются в Vercel
(preset "Other", без build command). Домен не нужен — Vercel сам выдаёт alias.

## Что вписать при запуске токена
В `script.js`, в объекте `CONFIG`:
- `CA` — контракт токена (сейчас "NOT MINTED YET")
- `CHART_URL`, `BUY_URL`, `X_URL`, `TELEGRAM_URL` — реальные ссылки

После того как вписан `CA`, живые данные (цена/капа/ликвидность) в разделе
"Live Market" подтянутся с DexScreener автоматически, а кнопка копирования CA
заработает.
